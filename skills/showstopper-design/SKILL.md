# Showstopper design

Use this for a memorable, manipulable web experience. Begin with the material, audience and one action worth taking. A rotating object pasted beside a conventional hero section is not sufficient.

- Inspect the existing design and supplied references. Name the *principle* that makes the reference work, not the silhouette to copy. Offer materially different directions and get approval for one signature interaction.
- Compose a first frame that makes sense when frozen. Light the object to show its structure, reserve negative space for the title, and test the brightest pose against the text. Turn off particles while judging the composition.
- Build the central gesture before polishing the controls. A slider should alter a visible geometric feature, not just a label. Try the dependency-free `templates/sculpture.html` in a browser to see pointer and keyboard manipulation; treat it as a technical example rather than a template to recolor. For geometry, lighting and motion guidance see `references/sculpture-engine.md`.
- Share a single clock for passive motion. Respect reduced motion and pause while preserving direct keyboard manipulation. Provide an honest no-WebGL state and a non-gesture path to the content.
- Test pointer, keyboard and touch on the actual page. Inspect desktop, phone, open dialog and altered object. Ask which parts to keep before changing the artistic direction. Deliver an isolated prototype until the new direction is approved.
